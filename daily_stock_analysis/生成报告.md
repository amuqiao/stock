# 报告生成流程与命令示例

## 报告生成原理

报告是通过以下流程自动生成的：

1. **分析执行**：当运行 `python main.py` 时，系统会执行股票分析
2. **结果汇总**：分析完成后，系统会汇总所有股票的分析结果
3. **报告生成**：通过 `NotificationService` 生成 Markdown 格式的报告
4. **文件保存**：将报告保存到 `reports` 目录下

## 报告文件命名规则

- **个股分析报告**：`report_YYYYMMDD.md`
- **大盘复盘报告**：`market_review_YYYYMMDD.md`

## 生成报告的命令示例

### 1. 执行完整分析并生成报告

```bash
# 分析配置文件中的所有股票并生成报告
python main.py
```

### 2. 分析指定股票并生成报告

```bash
# 分析指定的股票代码并生成报告
python main.py --stocks 002202,600519,000001
```

### 3. 仅分析个股，跳过大盘复盘

```bash
# 分析指定股票，跳过大盘复盘
python main.py --stocks 002202,600519 --no-market-review
```

### 4. 分析并禁用通知，只生成本地报告

```bash
# 分析股票，只生成本地报告，不发送通知
python main.py --stocks 002202,600519 --no-notify
```

### 5. 仅大盘复盘报告

```bash
# 仅生成大盘复盘报告
python main.py --market-review
```

## 报告内容说明

- **决策仪表盘**：包含市场概览、重要信息、核心结论、数据透视、作战计划等
- **分析结果摘要**：按评分排序的股票分析结果
- **个股详细分析**：每只股票的详细分析，包括技术面、基本面、消息面等
- **大盘复盘**：市场整体情况分析

## 报告存储位置

报告文件存储在项目根目录的 `reports` 文件夹中：
- `/Users/wangqiao/Downloads/github_project/daily_stock_analysis/reports/`

例如：
- `/Users/wangqiao/Downloads/github_project/daily_stock_analysis/reports/report_20260311.md`
- `/Users/wangqiao/Downloads/github_project/daily_stock_analysis/reports/market_review_20260311.md`

## 注意事项

1. 报告文件会按照日期自动命名，每天的分析会生成新的报告文件
2. 如果需要保留历史报告，建议定期备份 `reports` 目录
3. 报告内容会根据配置的报告类型（simple/brief/full）有所不同
4. 大盘复盘报告只有在启用大盘复盘功能时才会生成
