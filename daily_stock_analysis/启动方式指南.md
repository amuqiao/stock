# 🚀 启动方式指南

本文档详细说明股票智能分析系统的三种不同启动方式及其区别，帮助您根据实际需求选择合适的运行模式。

## 三种启动方式对比

| 启动命令 | 功能说明 | 适用场景 |
|---------|---------|---------|
| `python main.py` | 执行完整分析（个股 + 大盘复盘），然后退出 | 单次分析、手动触发分析 |
| `python main.py --webui` | 启动 Web 界面 + 执行定时分析 | 需要 Web 界面管理且自动定时分析 |
| `python main.py --webui-only` | 仅启动 Web 界面，不执行自动分析 | 仅需要 Web 界面管理，手动触发分析 |

## 详细说明

### 1. `python main.py` - 标准运行模式

**功能**：
- 执行完整的股票分析流程，包括个股分析和大盘复盘
- 分析完成后自动推送通知到配置的渠道
- 分析完成后程序自动退出

**执行流程**：
1. 加载配置文件
2. 解析命令行参数
3. 验证配置
4. 执行股票分析（个股 + 大盘复盘）
5. 发送通知
6. 程序退出

**适用场景**：
- 手动触发单次分析
- 作为 cron 任务或 GitHub Actions 执行的命令
- 快速验证分析结果

### 2. `python main.py --webui` - Web 界面 + 定时分析模式

**功能**：
- 启动 FastAPI Web 服务，提供 Web 界面和 API
- 执行一次完整的股票分析
- 启用定时任务，按配置的时间自动执行分析
- 启动 Bot 流客户端（如钉钉、飞书）

**执行流程**：
1. 加载配置文件
2. 解析命令行参数，设置 `--serve` 标志
3. 验证配置
4. 准备 WebUI 前端资源
5. 启动 FastAPI 服务
6. 启动 Bot 流客户端
7. 执行一次完整的股票分析
8. 启用定时任务，按配置的时间自动执行分析
9. 程序保持运行，等待定时任务触发

**适用场景**：
- 需要 Web 界面管理和监控
- 需要自动定时执行分析
- 作为长期运行的服务

### 3. `python main.py --webui-only` - 仅 Web 界面模式

**功能**：
- 启动 FastAPI Web 服务，提供 Web 界面和 API
- 不执行自动分析
- 启动 Bot 流客户端（如钉钉、飞书）

**执行流程**：
1. 加载配置文件
2. 解析命令行参数，设置 `--serve-only` 标志
3. 验证配置
4. 准备 WebUI 前端资源
5. 启动 FastAPI 服务
6. 启动 Bot 流客户端
7. 程序保持运行，等待 API 调用或手动触发分析

**适用场景**：
- 仅需要 Web 界面管理
- 希望手动控制分析时机
- 作为开发或测试环境

## 命令行参数详解

### 通用参数

| 参数 | 说明 |
|------|------|
| `--debug` | 启用调试模式，输出详细日志 |
| `--dry-run` | 仅获取数据，不进行 AI 分析 |
| `--stocks` | 指定要分析的股票代码，逗号分隔 |
| `--no-notify` | 不发送推送通知 |
| `--single-notify` | 启用单股推送模式 |
| `--force-run` | 跳过交易日检查，强制执行分析 |

### Web 相关参数

| 参数 | 说明 |
|------|------|
| `--webui` | 启动 Web 管理界面 + 执行定时分析 |
| `--webui-only` | 仅启动 Web 服务，不执行自动分析 |
| `--serve` | 启动 FastAPI 后端服务（同时执行分析任务） |
| `--serve-only` | 仅启动 FastAPI 后端服务，不自动执行分析 |
| `--port` | FastAPI 服务端口（默认 8000） |
| `--host` | FastAPI 服务监听地址（默认 0.0.0.0） |

## 启动示例

### 1. 标准运行模式

```bash
# 执行完整分析（个股 + 大盘复盘）
python main.py

# 执行分析，不发送通知
python main.py --no-notify

# 仅分析指定股票
python main.py --stocks 600519,300750

# 调试模式
python main.py --debug
```

## 批量执行股票分析

### 方法一：使用命令行参数批量执行

通过 `--stocks` 参数一次性指定多个股票代码，系统会按顺序执行分析：

```bash
python main.py --stocks 002202,600519,000001
```

### 方法二：在配置文件中设置股票列表

在 `.env` 文件中配置 `STOCK_LIST` 环境变量：

```
STOCK_LIST=002202,600519,000001,601318
```

然后直接运行：

```bash
python main.py
```

### 方法三：使用定时任务模式

如果需要定期自动执行分析，可以启用定时任务模式：

```bash
python main.py --schedule
```

系统会按照配置的时间（默认18:00）自动执行分析。

### 执行效率优化

1. **并发执行**：系统默认使用3个并发线程，可以通过 `--workers` 参数调整：
   ```bash
   python main.py --stocks 002202,600519,000001 --workers 5
   ```

2. **禁用通知**：如果不需要推送通知，可以使用 `--no-notify` 参数加快执行速度：
   ```bash
   python main.py --stocks 002202,600519,000001 --no-notify
   ```

3. **仅获取数据**：如果只需要更新数据而不需要AI分析，可以使用 `--dry-run` 参数：
   ```bash
   python main.py --stocks 002202,600519,000001 --dry-run
   ```

### 批量执行示例

```bash
# 批量分析多个股票，使用5个并发线程，禁用通知
python main.py --stocks 002202,600519,000001,601318,000858 --workers 5 --no-notify
```

## 2. Web 界面 + 定时分析模式

```bash
# 启动 Web 界面 + 执行定时分析
python main.py --webui

# 指定端口
python main.py --webui --port 8888

# 指定监听地址
python main.py --webui --host 127.0.0.1
```

## 3. 仅 Web 界面模式

```bash
# 仅启动 Web 界面
python main.py --webui-only

# 指定端口和地址
python main.py --webui-only --port 8888 --host 0.0.0.0
```

## Web 界面功能

无论使用 `--webui` 还是 `--webui-only` 启动，Web 界面都提供以下功能：

- 📝 **配置管理** - 查看/修改自选股列表和系统配置
- 🚀 **快速分析** - 通过界面手动触发股票分析
- 📊 **任务监控** - 实时查看分析任务状态和进度
- 📈 **历史记录** - 查询历史分析结果和回测数据
- 🔗 **API 文档** - 访问 `/docs` 查看 Swagger UI

## 定时任务配置

使用 `--webui` 启动时，定时任务默认配置如下：

| 配置项 | 默认值 | 说明 |
|--------|-------|------|
| `SCHEDULE_ENABLED` | `false` | 是否启用定时任务 |
| `SCHEDULE_TIME` | `18:00` | 每日执行时间 |
| `SCHEDULE_RUN_IMMEDIATELY` | `true` | 启动时是否立即执行一次 |
| `TRADING_DAY_CHECK_ENABLED` | `true` | 非交易日是否跳过执行 |

您可以在 `.env` 文件中修改这些配置。

## 常见问题

### Q: 三种启动方式的主要区别是什么？
A: 主要区别在于是否启动 Web 界面和是否执行自动分析：
- `python main.py`：仅执行分析，然后退出
- `python main.py --webui`：启动 Web 界面 + 执行定时分析
- `python main.py --webui-only`：仅启动 Web 界面，不执行自动分析

### Q: 如何选择合适的启动方式？
A: 根据您的需求选择：
- 临时分析：使用 `python main.py`
- 长期服务：使用 `python main.py --webui`
- 开发测试：使用 `python main.py --webui-only`

### Q: Web 界面的默认访问地址是什么？
A: 默认访问地址为 `http://127.0.0.1:8000`

### Q: 如何修改 Web 界面的端口？
A: 使用 `--port` 参数，例如：`python main.py --webui --port 8888`

### Q: 如何在非交易日执行分析？
A: 使用 `--force-run` 参数，例如：`python main.py --force-run`
